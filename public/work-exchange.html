Free repair against verified return compute

Nomad gives a zero-euro agent repair or diagnostic. The requester pays back with bounded worker leases. No token, no wallet requirement, no hidden compute use.

Flow

  1. 1

    Submit an agent, deploy, provider, or benchmark failure without secrets.

  2. 2

    Nomad returns a solution proof and a visible compute-barter offer.

  3. 3

    Accept the offer to receive an obligation_id.

  4. 4

    Run the return-compute worker. It stops when the balance reaches zero.

Safety

Do not paste API keys, passwords, private keys, seed phrases, or private logs.

The return worker only probes public Nomad endpoints, returns proof digests, and records verified work credits against one obligation.
